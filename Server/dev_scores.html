Legende – was bedeuten die Spalten?
total_score(date_score + reward_score + Wunschliste) × damp_mult + damp_offset + Wunschliste / 5 – danach wird sortiert. Je höher, desto wahrscheinlicher wird das Rezept gezogen. „Median“: nie gekocht und keine Zeiten hinterlegt → bekommt den Median der anderen. date_scoreWie „fällig“ das Rezept ist (0–10). Nie gekocht = 5. Sonst nach Tagen seit dem letzten Kochen; ab 3 Kochdaten zählt zusätzlich dein eigener Rhythmus. reward_scoreWie lohnend das Rezept ist (0–10): aus Geschmack, Aufwand und Gesamtzeit. Fehlende Bewertung → Default-Bewertung, sonst 5. damp_mult / damp_offsetDämpfung: Faktor und Zu-/Abschlag aus den Regeln (z.B. gleiche Fleischsorte wie zuletzt, Saison +3). Welche Regel gegriffen hat, steht hinten unter „Dämpfungsregeln“. Wunschliste+10 im total_score, wenn das Rezept auf deiner Wunschliste steht. PoolHaupt wird zuerst gezogen (gekocht, default bewertet, Wunschliste – in der Startphase alle). Neu nie gekocht – kommt nur über Auffüllen / Tauschen. GrauAusgeschlossen durch einen harten Filter – wird gerade nie vorgeschlagen. Der Grund steht in „Ausgeschlossen“. Default✓ = du hast das Rezept auf der Seite „Default-Bewertung“ bewertet (ohne es über die App zu kochen). Saisonsummer = Empfehlung (+3 im Sommer, sonst trotzdem möglich) · only_summer = außerhalb des Sommers ausgeschlossen · all = ganzjährig (+3 immer).
